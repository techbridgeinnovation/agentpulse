Install a version by its number or tag:

```bash [Python]
pip install techbridge-agentpulse==0.6.1
```

```bash [TypeScript]
npm install https://github.com/techbridgeinnovation/agentpulse/releases/download/typescript/v0.2.0/techbridge-agentpulse-0.2.0.tgz
```

```bash [Go]
go get github.com/techbridgeinnovation/agentpulse/recorder@v0.3.0
```
